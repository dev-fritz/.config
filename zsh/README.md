# zsh

The login shell. Prompt, history, plugins and the fastfetch greeting that opens
every terminal.

## Why it is in here

`.zshrc` belongs in `$HOME`, not in `~/.config` — zsh looks for it there and
nowhere else unless `ZDOTDIR` is set. But `$HOME` is not versioned by this
repository, so on a reinstall it would be the one file left behind.

The file therefore lives here and is linked into place:

```sh
~/.zshrc -> ~/.config/zsh/.zshrc
```

[`../install.sh`](../install.sh) creates that link (moving any existing
`~/.zshrc` to `~/.zshrc.bak-<date>` first) and makes zsh the login shell.
Setting `ZDOTDIR` would have worked too, but it has to be exported before the
shell starts — which means editing `/etc/zsh/zshenv`, a file outside this
repository. A symlink keeps everything in one place.

## What is configured

| Block | What it does |
|---|---|
| oh-my-zsh | framework and the `robbyrussell` prompt, plugin `git` |
| autosuggestions | greys in the last matching command from the history, `→` accepts |
| syntax highlighting | colors the line as it is typed: green = the command exists |
| `EDITOR` / `VISUAL` | `nvim`, so `git commit` and `systemctl edit` open the right editor |
| `LESS=-FRX` | pagers keep colors and do not clear the screen on exit |
| `NEWT_COLORS_FILE` | palette for `nmtui` and `whiptail`, generated by [`../theme/apply.py`](../theme/apply.py) |
| history | 50 000 entries, shared between terminals, timestamped, no duplicates |
| fastfetch | the greeting, once per terminal — guarded so it never runs in scripts, pipes or `:terminal` |

The two plugins are sourced by hand instead of through `plugins=(...)` for two
reasons: `zsh-syntax-highlighting` has to be the **last** thing that wraps the
command line, and the loop skips a plugin that is not installed instead of
printing an error on every start.

## Dependencies

| Package | For | Required |
|---|---|---|
| `zsh` | the shell | yes |
| `oh-my-zsh` | the framework the file sources — cloned by `install.sh` | yes |
| `zsh-autosuggestions` | history suggestions | no |
| `zsh-syntax-highlighting` | colored input line | no |
| `fastfetch` | the greeting ([`../fastfetch/`](../fastfetch/)) | no |

Both plugins are looked for in `/usr/share/zsh/plugins` (the Arch packages) and
in `~/.oh-my-zsh/custom/plugins` (a manual clone), in that order.

## Changing it

The file is read on every new interactive shell, so a new terminal already has
the change. To reload the current one:

```sh
source ~/.zshrc
```

To turn the fastfetch greeting off, comment out the block at the end. To skip it
just once: `FASTFETCH_SHOWN=1 kitty`.
